# Student Grade Manager - CLI Version (v1.0)

A simple Java command-line application that allows you to input student names and grades, with full exception handling including custom exceptions.

## Features

- Command-line input
- Grade validation
- Custom exceptions (e.g., `InvalidGradeException`)
- File writing for storing student data
- Introductory use of `try-catch`, `throw`, `throws`, and `finally`

## How to Run

1. Open this branch in IntelliJ IDEA.
2. Run the main class (e.g., `StudentGradeManagerCLI.java`).
3. Enter student details and test exception handling.

## 🛠 Technologies

- Java 17+
- No external libraries required
