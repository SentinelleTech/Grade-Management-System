# Student Grade Manager - JavaFX GUI (v2.0)

This version of the Student Grade Manager features a JavaFX graphical user interface. It's an upgrade from the CLI version with TableView display and user-friendly inputs.

## Features

- JavaFX-based GUI
- TextArea to display students and grades
- Real-time validation using text field listeners
- GUI-based error alerts for invalid input
- Enhanced UX from v1.0

## How to Run

1. Open the project in IntelliJ IDEA.
2. Ensure JavaFX is properly set up (add JavaFX SDK in Project Structure).
3. Run `GradeManagerApp.java`.

## 🛠 Technologies

- Java 17+
- JavaFX
